## Format Used Per Topic

- Code example where useful

## Suggested Study Order

Start with fundamentals, then move into pointers and memory management before studying object-oriented C++ and the STL. For senior interviews, focus heavily on undefined behavior, RAII, move semantics, concurrency, performance, and debugging tradeoffs.
